# Markdown Viewer PWA

スマートフォンでも使えるMarkdownビューアーのProgressive Web App (PWA)版です。

## 特徴

### 📋 目次機能
- 見出しから自動的に目次を生成（日本語の見出しにも対応した GitHub 互換のアンカー）
- ツリー表示：見出しごとに折りたたみ／すべて展開・折りたたみ
- 見出しの絞り込み検索（Enter で最初の候補へジャンプ）
- 現在位置のハイライト（親見出しも強調、目次も自動で追従スクロール）
- モバイルではボトムシート（右下のボタンで開く、下スワイプで閉じる）

### 🔢 行番号（元ファイル）
- 本文の左に、元の Markdown ファイルの行番号を表示（VSCode で開いたときと同じ番号）
- 見出し・段落・リストの各項目・表の各行・コードの各行に番号が付く
- コピーしても番号は含まれない。⋮ メニューで表示を切り替え

### 💻 コード表示
- 言語名つきのヘッダー（```の行）と **コピーボタン**
- **色分け**（highlight.js。40以上の言語。`hlsl` / `shader` は C++ の文法で近似）
- 折り返し表示の切り替え

### 📐 数式・図・注記
- **数式**（KaTeX）：`$...$`、`$$...$$`、` ```math `。`$5 と $10` のような金額は数式にならない
- **図**（Mermaid）：` ```mermaid ` をフローチャートなどの図で表示。「コード」ボタンで元のコードに切り替え
- **注記ボックス**：GitHub と同じ `> [!NOTE]` `> [!TIP]` `> [!IMPORTANT]` `> [!WARNING]` `> [!CAUTION]`
- Mermaid（3.5MB）と KaTeX は、その要素を含む文書を開いたときだけ読み込み、以後はオフラインでも使えるようキャッシュ

### 🈂️ Gemini で翻訳
- ナビバーの「文A」ボタンで、文書全体を Gemini で翻訳（もう一度押すと原文に戻る）
- 見出し・リスト・表・リンクなどの書式はそのまま。コード・数式・図は訳さない
- 訳せた部分から順に表示し、読んでいる位置は保ったまま。行番号・目次・文書内リンクも原文と同じ
- 訳文は端末内に保存され、同じ文書なら次回から API を呼ばずに表示
- 設定（⋮ →「Gemini 翻訳の設定」）：API キー、モデル（既定は `gemini-flash-latest`。「一覧を取得」で使えるモデルを選べる）、翻訳先（日本語 / English / 简体中文 / 한국어）
- API キーはこの端末のブラウザにのみ保存され、Gemini API 以外には送信されません

### 📱 PWA機能
- スマートフォンのホーム画面にインストール可能
- オフライン対応（基本機能）
- ネイティブアプリのような操作感
- モバイルブラウザ最適化

### 🎨 テーマ
- ダークテーマ固定

### 📊 読書支援機能
- 読書進捗バー（ページ上部）
- 読書統計（文字数・推定読書時間：日本語 約500字/分、英語 約200語/分で計算）
- トップに戻るボタン
- レスポンシブデザイン

### 🔍 ページ内検索
- 🔍ボタンまたは Ctrl+F（Mac は ⌘F）で検索バーを開く
- Enter で次へ、Shift+Enter で前へ、Esc で閉じる。件数を「3 / 12」のように表示
- インストール版 PWA ではブラウザのページ内検索が使えないので、アプリ側で用意しています

### 🕘 最近開いたファイル・続きから読む
- 開いたファイルの内容と、最後に読んでいた位置（元ファイルの行番号）をこの端末内（IndexedDB）に保存
- 最初の画面の「最近開いたファイル」から、前回の続きの位置で開ける（「最初から」で先頭へ）
- 保存は最大15件。× で履歴から削除。データは外部に送信されません

### 🌐 翻訳しやすくする工夫
- 本文の言語を自動で判定して `<html lang>` に設定（英語の文書で Chrome が翻訳を提案するように）
- コード部分には `translate="no"` を付けて、翻訳で壊れないように

### 📄 ファイル入力方法
- **ファイル選択**: 📁ボタンでMarkdownファイルを選択
- **ドラッグ&ドロップ**: ファイルを直接ドロップ
- **クリップボード**: コピーしたMarkdownテキストを貼り付け（Ctrl+V でも可）
- **URL**: Markdown の URL を入力。GitHub のファイルページ・リポジトリのトップ（README）・Gist の URL は自動で raw に変換
  - `https://toya-mimura.github.io/chrome-md-pwa/?url=<MarkdownのURL>` の形で、直接開くリンクも作れます
  - URL から開いた文書内の相対リンク（別の .md）や画像もそのまま表示できます
- **共有メニュー（Android）**: インストール版で、ファイルアプリやブラウザの「共有」→「MD Viewer」で開く
- **サンプル表示**: 機能確認用のサンプルコンテンツ

## 公開のしかた（最初に1回だけ）

PWA は HTTPS で配信する必要があります。いちばん手軽なのは GitHub Pages です。

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、**Branch** でデフォルトブランチ・`/ (root)` を選んで **Save**
3. 1〜2分後に `https://toya-mimura.github.io/chrome-md-pwa/` で開けるようになる

（Cloudflare Pages でも、リポジトリを接続してビルドコマンドなし・出力ディレクトリ `/` で公開できます）

## インストール方法

### デスクトップブラウザ
1. このPWAにアクセス
2. アドレスバーの「インストール」ボタンをクリック
3. 確認ダイアログで「インストール」を選択

### モバイルブラウザ（Chrome/Safari）
1. このPWAにアクセス
2. 画面下部に表示されるインストールプロンプトで「インストール」をタップ
3. または、ブラウザメニューから「ホーム画面に追加」を選択

## 使用方法

### 基本的な使い方
1. PWAを開く
2. 以下のいずれかの方法でMarkdownを読み込む：
   - 📁「ファイルを選択」ボタンで.mdファイルを選択
   - ファイルをドラッグ&ドロップエリアにドロップ
   - 📋「クリップボードから貼り付け」でコピーしたテキストを貼り付け
   - 📖「サンプルを表示」で機能を確認

### 目次の使用方法
- 📋「目次」ボタンで目次パネルの表示/非表示を切り替え
- 目次の項目をクリックして該当箇所にジャンプ
- スクロールに応じて現在位置がハイライト表示

### 表示設定
- 画面右上の ⋮ メニューから、行番号（元ファイル）・コードの折り返しを切り替え
- 設定は自動的に保存され、次回起動時に復元

### Android の「共有」から開く
1. Chrome でこのアプリを開き、メニューから「ホーム画面に追加（インストール）」
2. ファイルアプリなどで .md ファイルを選び「共有」→「MD Viewer」
   - テキストや URL を共有した場合は、その内容（URL なら中身）を表示します
   - すでにインストールしている場合、共有先に出てくるまで少し時間がかかることがあります。出てこない場合はいったんアンインストールして入れ直してください
   - ファイルアプリによっては .md が「テキスト」と認識されず、共有先に出ないことがあります

### モバイルでの使用
- 目次は右下のボタンからボトムシートで表示
- 目次の項目をタップするとシートが閉じて該当箇所へ移動

## 技術仕様

### 対応ブラウザ
- Chrome 88+
- Safari 14+
- Firefox 85+
- Edge 88+

### 対応ファイル形式
- Markdown (.md, .markdown)
- プレーンテキスト (.txt)

### PWA機能
- Web App Manifest
- Service Worker（オフライン対応）
- File Handler API（対応ブラウザのみ）

## 開発・カスタマイズ

### ファイル構成
```
chrome-md-pwa/
├── index.html          # メインHTML
├── manifest.json       # PWAマニフェスト
├── sw.js              # Service Worker
├── css/
│   ├── github-markdown.css  # Markdownスタイル
│   └── app.css             # PWA固有スタイル
├── js/
│   ├── app.js             # メインJavaScript
│   ├── library.js         # 最近開いたファイル・読んだ位置（IndexedDB）
│   ├── search.js          # ページ内検索
│   ├── rich.js            # 色分け・数式・図・注記ボックス・コピー
│   ├── translate.js       # Gemini 翻訳
│   └── vendor/
│       ├── marked.min.js  # Markdownパーサー
│       ├── purify.min.js  # DOMPurify（XSS対策のサニタイズ）
│       ├── highlight.min.js  # highlight.js
│       ├── mermaid.min.js    # Mermaid（使うときだけ読み込み）
│       └── katex/            # KaTeX（使うときだけ読み込み）
├── icons/             # PWAアイコン（16/48/128/192/512 + maskable）
└── test-markdown.md   # サンプルファイル
```

### ローカル開発
```bash
# HTTPSサーバーが必要（PWA機能のため）
python -m http.server 8000
# または
npx serve .
```

### カスタマイズ
- `css/app.css`: PWA固有のスタイル
- `css/github-markdown.css`: Markdownの表示スタイル
- `js/app.js`: アプリケーションロジック
- `manifest.json`: PWA設定
- `sw.js`: 更新を反映させたいときは `CACHE_VERSION` を上げる
