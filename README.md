# Markdown Viewer PWA

スマートフォンでも使えるMarkdownビューアーのProgressive Web App (PWA)版です。

## 特徴

### 📋 目次機能
- 見出しから自動的に目次を生成
- 階層構造に対応した見やすい表示
- クリックで該当箇所にスムーズスクロール
- 現在位置のハイライト表示（スクロールスパイ）

### 📱 PWA機能
- スマートフォンのホーム画面にインストール可能
- オフライン対応（基本機能）
- ネイティブアプリのような操作感
- モバイルブラウザ最適化

### 🎨 テーマ機能
- **システムテーマ**: OSの設定に従って自動切り替え
- **ライトモード**: 明るい背景での表示
- **ダークモード**: 暗い背景での表示

### 📊 読書支援機能
- 読書進捗バー（ページ上部）
- 読書統計（文字数・推定読書時間）
- トップに戻るボタン
- レスポンシブデザイン

### 📄 ファイル入力方法
- **ファイル選択**: 📁ボタンでMarkdownファイルを選択
- **ドラッグ&ドロップ**: ファイルを直接ドロップ
- **クリップボード**: コピーしたMarkdownテキストを貼り付け
- **サンプル表示**: 機能確認用のサンプルコンテンツ

## インストール方法

### デスクトップブラウザ
1. このPWAにアクセス
2. アドレスバーの「インストール」ボタンをクリック
3. 確認ダイアログで「インストール」を選択

### モバイルブラウザ（Chrome/Safari）
1. このPWAにアクセス
2. 画面下部に表示されるインストールプロンプトで「インストール」をタップ
3. または、ブラウザメニューから「ホーム画面に追加」を選択

## 使用方法

### 基本的な使い方
1. PWAを開く
2. 以下のいずれかの方法でMarkdownを読み込む：
   - 📁「ファイルを選択」ボタンで.mdファイルを選択
   - ファイルをドラッグ&ドロップエリアにドロップ
   - 📋「クリップボードから貼り付け」でコピーしたテキストを貼り付け
   - 📖「サンプルを表示」で機能を確認

### 目次の使用方法
- 📋「目次」ボタンで目次パネルの表示/非表示を切り替え
- 目次の項目をクリックして該当箇所にジャンプ
- スクロールに応じて現在位置がハイライト表示

### テーマの変更
- 画面右上のテーマセレクターで切り替え
- 設定は自動的に保存され、次回起動時に復元

### モバイルでの使用
- タッチ操作に最適化されたインターフェース
- 目次パネルはモバイルでは上下に折りたたみ表示
- スワイプやピンチ操作に対応

## 技術仕様

### 対応ブラウザ
- Chrome 88+
- Safari 14+
- Firefox 85+
- Edge 88+

### 対応ファイル形式
- Markdown (.md, .markdown)
- プレーンテキスト (.txt)

### PWA機能
- Web App Manifest
- Service Worker（オフライン対応）
- File Handler API（対応ブラウザのみ）

## 開発・カスタマイズ

### ファイル構成
```
chrome-md-pwa/
├── index.html          # メインHTML
├── manifest.json       # PWAマニフェスト
├── sw.js              # Service Worker
├── css/
│   ├── github-markdown.css  # Markdownスタイル
│   └── app.css             # PWA固有スタイル
├── js/
│   └── app.js             # メインJavaScript
├── icons/             # PWAアイコン
├── marked.min.js      # Markdownパーサー
└── test-markdown.md   # サンプルファイル
```

### ローカル開発
```bash
# HTTPSサーバーが必要（PWA機能のため）
python -m http.server 8000
# または
npx serve .
```

### カスタマイズ
- `css/app.css`: PWA固有のスタイル
- `css/github-markdown.css`: Markdownの表示スタイル
- `js/app.js`: アプリケーションロジック
- `manifest.json`: PWA設定
